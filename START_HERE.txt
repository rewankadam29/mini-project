EXAM SEATING GENERATOR — PHASE 3

1. Extract the entire ZIP before opening files.
2. Open public/index.html in Chrome or Edge.
3. Click Load Demo Inputs.
4. Click Generate Seating Arrangement.
5. Switch to Column-Based Seating and generate again.

For the backend demonstration:
Open a terminal in this folder and run: npm run demo
Open http://localhost:3000
Node.js 20.12 or newer is required. No npm install is needed for this mode.
